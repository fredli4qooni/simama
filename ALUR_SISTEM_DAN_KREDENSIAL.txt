C. PENJELASAN ALUR SISTEM (END-TO-END WORKFLOW)
================================================================================

Terdapat 2 skema magang di SIMAMA:
1. Magang Program Studi (Alur Reguler)
2. Magang Mandiri (Alur Ringkas / Inisiatif Mitra)

--------------------------------------------------------------------------------
1. ALUR MAGANG PROGRAM STUDI (REGULER)
--------------------------------------------------------------------------------
Tahap 1: Pengajuan oleh Mahasiswa
  - Mahasiswa login dan masuk ke menu "Pengajuan Magang".
  - Mahasiswa memilih jenis "Magang Prodi" dan tipe (Individu / Kelompok).
  - Mahasiswa mengisi nama instansi, alamat lengkap, tanggal mulai & selesai.
  - Mahasiswa mengunggah berkas persyaratan: KTM, Transkrip Nilai, dan Slip Pembayaran SPP/UKT Terakhir (PDF/JPG/PNG).
  - Berkas diajukan ke sistem, status berubah menjadi: "Pending".

Tahap 2: Verifikasi Berkas oleh Admin Prodi
  - Admin login dan masuk ke menu "Verifikasi Berkas".
  - Admin memeriksa kelayakan akademik pemohon dan anggota tim.
  - Admin mengecek keabsahan berkas KTM, Transkrip Nilai, & Slip SPP.
  - Admin menekan tombol "Setujui" (Approved) atau "Tolak" (Rejected).
  - Jika disetujui, status berubah menjadi: "Approved".

Tahap 3: Surat Pengantar & Konfirmasi Mitra
  - Mahasiswa yang disetujui dapat mengunduh dokumen resmi "Surat Permohonan Izin Magang"
    berformat .DOCX otomatis (nomor dinamis WD1/PP.00.[d/m/Y], tanggal hari ini, dan tabel peserta terisi)
    serta opsi cetak langsung Web Print.
  - Mahasiswa meminta stempel/ttd basah di fakultas/prodi lalu membawanya
    ke pimpinan instansi tempat magang.
  - Instansi menerbitkan Surat Balasan Persetujuan / Acceptance Letter.
  - Mahasiswa mengunggah scan Surat Balasan tersebut ke Document Hub SIMAMA.

Tahap 4: Penetapan DPL oleh Admin
  - Admin masuk ke menu "Penetapan DPL".
  - Admin memilih Dosen Pembimbing Lapangan (DPL) untuk kelompok/mahasiswa tsb.
  - Status magang resmi aktif: "Active".

Tahap 5: Pelaksanaan Magang (Presensi & Logbook)
  - Mahasiswa login setiap hari kerja ke menu "Presensi" untuk mencatat
    kehadiran (Hadir/Izin/Sakit), jam, titik koordinat GPS, dan foto bukti.
  - Mahasiswa mengisi menu "Logbook" berkala mencakup aktivitas harian,
    analisis permasalahan, serta dokumentasi kegiatan.
  - Mahasiswa dapat mencetak / mengunduh rekap "Logbook Kegiatan (PDF)" kapan saja secara berkala.
  - DPL login ke menu "Pemantauan Magang" untuk memantau rekap absensi serta
    memberikan feedback / arahan tertulis pada setiap logbook mahasiswa.

Tahap 6: Laporan Akhir & Blanko Nilai Mitra
  - Mahasiswa mengunduh berkas "Panduan KKN Tematik & Template Laporan (DOCX)"
    dan menyusun naskah laporan akhir.
  - Mahasiswa mengunggah file PDF "Laporan Akhir Magang" ke sistem.
  - Mahasiswa mengunduh berkas "Blanko Penilaian Mitra (DOCX)" (10 aspek evaluasi)
    untuk diserahkan kepada mentor/pembimbing lapangan instansi agar diisi,
    diberi nilai angka, ditandatangani, dan distempel resmi.

Tahap 7: Evaluasi & Perhitungan Nilai Otomatis oleh DPL
  - DPL login ke menu "Evaluasi & Penilaian".
  - DPL memasukkan 2 komponen nilai:
    1. Nilai Dosen Pembimbing (DPL) (Bobot 50%) -> berdasarkan logbook & bimbingan
    2. Nilai Pembimbing Instansi Mitra (Bobot 50%) -> dari lembar nilai mitra
  - DPL mengunggah berkas fisik bukti penilaian:
    * Scan Formulir Nilai Instansi Mitra
    * Scan Lembar Nilai Resmi DPL / Prodi
  - DPL menuliskan catatan/komentar evaluasi kinerja mahasiswa.
  - Sistem secara otomatis menghitung nilai rata-rata:
      NILAI AKHIR = (Nilai Instansi + Nilai DPL) / 2
  - Status magang otomatis diperbarui menjadi: "Selesai" dan terbit (published_at).
  - DPL dapat langsung mencetak "Lembar Penilaian Magang (PDF)" resmi.

Tahap 8: Transparansi Nilai Mahasiswa & Rekapitulasi Admin
  - Mahasiswa login -> Dashboard & Document Hub:
    * Mahasiswa langsung melihat rincian Nilai Instansi, Nilai DPL,
      Nilai Akhir Rata-rata, Catatan DPL, dan Predikat Huruf Mutu.
    * Mahasiswa dapat mengunduh sendiri "Lembar Penilaian (PDF)" resmi.
  - Admin login -> Menu "Rekap Nilai":
    * Admin melihat tabel rekapitulasi seluruh nilai mahasiswa prodi SI.
    * Admin dapat mencetak "Rekapitulasi Nilai Akhir Magang (PDF)" resmi
      bertandatangan Kaprodi SI.


--------------------------------------------------------------------------------
2. ALUR MAGANG MANDIRI (INISIATIF SENDIRI / MSIB / MITRA KHUSUS)
--------------------------------------------------------------------------------
Tahap 1: Registrasi Mandiri Fleksibel
  - Mahasiswa memilih jenis "Magang Mandiri" saat pendaftaran.
  - Mahasiswa mengisi profil instansi, mengunggah berkas akademik (KTM, Transkrip, Slip SPP),
    dan dapat langsung melampirkan berkas bukti penerimaan / MoU mitra jika sudah ada.
  - Jalur ini BYPASS pencetakan surat pengantar manual kampus.

Tahap 2: Verifikasi & Penetapan DPL Langsung
  - Admin memeriksa bukti penerimaan mandiri yang diunggah.
  - Admin langsung menetapkan DPL untuk membimbing dan menilai kegiatan.

Tahap 3: Pelaksanaan & Penyerahan Lembar Nilai
  - Mahasiswa mengunduh "Blanko Penilaian Mitra (DOCX)" dari sistem SIMAMA.
  - Mentor instansi mengisi dan menstempel lembar nilai tersebut.
  - Mahasiswa mengunggah berkas bukti nilai mitra tersebut ke kartu bukti mandiri.

Tahap 4: Penilaian DPL & Terbitnya Nilai Akhir
  - DPL memeriksa bukti berkas mitra melalui tombol "Lihat Bukti Berkas".
  - DPL menginput Nilai Instansi dan Nilai DPL.
  - Sistem menghitung nilai akhir rata-rata dan menerbitkan lembar nilai resmi.
